## 比較表の再整理（2026-09-22）

右列の「確認する」という案内文を撤去し、両列を「刺激・剥離」「日常生活」「施術の選び方」「成分とアプローチ」「目指す変化」の同じ比較軸へ変更。当店は肌を見極め、刺激・剥離を抑えながら効果を引き出すために選択・調整する説明とし、効果の最大化を保証する表現にはしない。

当店の根拠は公式ハーブピーリングページとユーザーが確定した4タイプ。右列はGREEN PEELの公式説明（https://schrammek.co.jp/green-peel/ ：剥離のある・ない施術、1day・数日間のケア、すぐメイクできるコース、天然ハーブ、肌質への持続的なアプローチ）等で確認した施術例を整理。一律に「強い刺激」「短期的な効果だけ」とする比較は避け、ブランドを超えた網羅調査や優越性の実証ではないことを注記した。LPには外部リンクを追加していない。

追加指示で、比較対象を列名から「剥離を伴う・数日間のケア型」に限定。刺激・生活制限・メイク・施術後サポートの4行に短文化。右列の制限・専用ケア・再来店は上記公式ページの5daysの実例に基づく。市場に多いという割合や他社全体の劣位は断定しない。当店の「基本的に生活制限なし」「メイクは翌日から」はユーザー確認による。既存FAQの直後メイク可を翌日からに統一し、当日のサウナ・長時間入浴等の例外は維持・表内にも表示する。

さらに指定の注記冒頭1文を削除し、「浸透技術」「成分の開発・評価」の2行を追加。ユーザー指摘を受け、自社公式の「創薬会社・大学病院との共同開発」「外部試験機関による原料評価」を改めて確認し、具体的に記載。リブスピキュールとImSを組み合わせる設計を紹介する。共同開発を、大学が施術効果を証明したという意味には置き換えない。他社全体への「成分が肌に届かない」「根拠がない」という断定は未確認のため掲載しない。微細針を用いない施術の例は上記GREEN PEEL公式の素材説明に基づく。

浸透技術の説明を「組み合わせ」から「リブスピキュール™の微細孔にImSなどを充填し、針とともに成分を肌へ届ける設計」へ具体化。公式施術ページの「スピキュールの微細孔にImSなどの成分を充填」の記載とユーザー指示に基づく。表の見出しも同じ仕組みを端的に伝える文言へ変更。到達する深さや施術結果の保証は追加していない。

比較表の刺激・剥離と浸透技術のセルを短文化。「肌に合わせて選択／刺激・剥離を抑え、効果を追求」「微細針の中にImS／成分を充填し、肌へ届ける」とした。「コースも」は「コースがある」に統一。市場割合を裏付ける資料がないため、「多い」という頻度の断定は加えていない。
