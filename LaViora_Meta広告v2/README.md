共感章に生成イラストを追加。制作方法・プロンプトは [制作記録](../docs/empathy-illustration-v1.md) を参照。

配合と施術工程は [公式の施術説明](https://laviora-clinical.jp/peeling/) と [初回来店ガイド](https://laviora-clinical.jp/beginner/) を確認。ImS、リブスピキュール、施術後の保湿成分（ヒアルロン酸・コラーゲン・ベタイン等）の説明に限定し、配合量や肌内部への到達・細胞増殖の効果は追加していない。

公式施術説明の「3日間で細胞量10.1倍」はImS細胞そのものと一般幹細胞の培養比較で、顧客の肌細胞が施術後に増えたことを示す試験ではない。製品の施術試験資料は未確認のため、肌細胞が増える・再生するという断定は掲載していない。研究と施術の効果は区別する。LP内には外部リンクを追加していない。

## ハーブピーリング全体の設計へ再構成

2026-09-21、[こだわりのハーブピーリング](https://laviora-clinical.jp/peeling/)を再確認。ユーザー指定の見出し「再生医療技術と肌理論から考えられた／肌を育てるサロンケア」に変更。ImSだけを主役にした大きな成分カードを撤去し、「呼び起こす・育てる・守り抜く」の3つの視点を同じ見出し階層で説明した。

- リブスピキュールによる物理的アプローチ、ImSを含む成分と施術の組み合わせ、施術後の保護・保湿を一体として紹介。
- 仕上げのケアでは、公式掲載のフラーレン・SOD・植物エキス・保湿成分に触れる。細胞増殖、基底層到達、再発防止などの施術効果は断定しない。
- 肌状態に加え、刺激への不安・翌日の予定も考慮するカスタマイズにつなぐ。公式ページのタイプ数とは差があるが、LP用に確定しているCalm⁺／Calm／Core／Boostの4タイプは維持。
- 原因章末尾からも、ImS単体ではなく施術設計全体へ接続。V1、価格・実績数値、症例・体験談、予約導線は変更していない。

追加のユーザー指示で、共感章の鏡の前の女性イラストをページから削除。画像枠・専用余白も撤去し、見出しの直後に悩みの文章が続く構成へ戻した。画像と制作記録のファイルは履歴・再利用用として保持するが、ページでは読み込まない。
