# V2：顧問の助言と過去の修正指示の再点検

## 方針

「初めてのエステを検討する20代」が、自分に合う肌ケアを相談する理由を感じられる記事LP。コンセプト自体をコピーとして掲載せず、ニキビ・ニキビ跡への共感を入口に、肌荒れ全体を見直す構成にする。

原本V1は変更しない。今回の変更対象はV2のみ。変更前のV2はコミット `a756401` で保持。

## 指摘と反映

| 顧問・ユーザーの指摘 | 今回の反映 |
| --- | --- |
| トップ画像が大きい、よくある写真で印象に残らない | 冒頭の実際の症例と直後の同一症例の重複を解消。指定症例を先頭に、7件の比較写真を1つの横スライドに集約。 |
| 綺麗なコピーだけで読み進める理由がない | 「また肌荒れ…」という日常の感情から、症例、予定前の肌荒れ・メイク・SNSで買ったケアへの共感へ接続。 |
| 原因と対策をつなげる | 角層の比較図と乾燥・刺激・皮脂の説明を短く整理。洗い方・保湿・ケアの負担の見直しから、肌確認と施術選択へつなぐ。ホームケアが無意味とは表現しない。 |
| 説明の重複・無駄な余白 | 独立して重複していた肌確認の章を統合。4タイプ、相談内容、品質、施術の流れを読みやすく整理。 |
| 実績・体験談で裏付ける | 指定5名の実写真と体験談、口コミ、リピート率、4部門受賞を維持。体験談を別人の症例と対応づけない。 |
| 安心材料を残す | 完全個室、肌質管理士、製造・処方・品質試験、365日相談、都度払いの章を維持。 |
| 予約まで分かりやすく | 対策の後に料金へのページ内リンクを追加。初回クーポン・2回目以降・追加部位の料金を集約。最終メッセージの下にもLINEボタンを追加。 |
| ブランドらしいデザインを維持 | ベージュ・ゴールド・明朝体の既存デザインを継承。副社長の写真は小さなプロフィールとして維持。 |

## 維持した個別指示

- 症例7件、体験談5名。症例の先頭は `case-v5-06.jpg`。症例は施術前／施術後と表示し、回数を見出しにしない。
- 体験談の順序は公式記事70、99、66、91、88。既存写真・体験談の本文は維持。
- タグの下に本文を配置。実際の手順以外で01、02などを連発しない。
- 365日相談のマーカー・太字、ダイヤモンドジェルパック、ダイヤモンドリペアクリーム、診断システムによる肌診断を維持。
- 副社長の名前の横に年齢は表示しない。美容業界30年以上、エステティシャン経験、学び続ける姿勢と初めての方へのメッセージを維持。
- ユーザーが「LPにある数値が最新・確定値」と確認。3％、Google口コミ2,300件、評価、累計施術件数、リピート率、店舗数等はLPの値を維持。公式サイトの別集計値へ置き換えていない。独立した数値監査を意味しない。

## 動作・表示確認

- Chromiumで幅320、375、390、430、1280pxを確認。
- 画像読み込み、横はみ出し、重複ID、ページ内リンク、JavaScriptエラーを検査。
- 症例7枚、体験談5枚の前後ボタン・端での無効化と開閉式説明を確認。
- 幅390pxでページ全体の高さは23,117pxから16,774pxへ約27％短縮。内容の重複・余白整理による参考値で、離脱率の計測値ではない。
- 冒頭の症例到達イベントの対象を、統合後の先頭写真に修正。外部の計測ツールは新規導入していない。

## 公開・運用上の留意点

V2のnoindexは検索掲載を抑える指定であり、閲覧制限ではない。写真の保存抑止は完全なコピー防止ではない。肌の外観・症例写真は今回加工していない。

掲載許諾の範囲、数値の根拠、広告表現の最終確認は運営者側で行う。今回の点検は法令適合性やMeta広告審査通過の保証ではない。離脱率・LINE遷移率・予約率は配信後に比較する。
